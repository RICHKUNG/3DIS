## Features

### Cascade Filtering
- Enabled by default: `stages.ssam.cascade_filtering: true`
- Maintains parent-child tree integrity during filtering
- Three rejection categories: area, stability, cascade
- Automatic fallback to traditional filtering if data lacks unique_id
- Can be re-applied via `filter_candidates.py --cascade`

### Dedup Timing Fix
- Deferred rejection processing until after prompt mapping
- Eager mapping establishment after prompt addition
- Resolves ~80% of timing-related orphans

### Unresolved Rejection Tracking
- New `unresolved_rejections` field in provenance trees
- Helps diagnose remaining orphan sources
- Exported in full metadata for analysis
